# E-Commerce RESTful API - Full CRUD

##  Project Description
This project is a simple E-commerce RESTful API built using Spring Boot.
The system allows managing products in an online store.  
It supports full CRUD operations:

- Create a product
- View products
- Update a product
- Delete a product

It also allows searching products by:
- Category
- Brand

---

##  Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Maven
- Postman (for testing)

---

##  Project Structure

- controller → Handles HTTP requests
- service → Contains business logic
- repository → Communicates with database
- model → Product entity class

---

##  Product Fields

Each product contains:

- id
- name
- description
- price
- category
- stockQuantity
- brand
